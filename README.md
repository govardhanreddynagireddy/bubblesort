Bubble Sort Animator

A simple Python project that visualizes the Bubble Sort algorithm step-by-step.
This helps beginners understand how bubble sort works internally by showing each comparison and swap.

** Features

Visual animation of bubble sort

Easy to understand

Beginner-friendly Python code

Shows comparisons and swaps in real-time

 What is Bubble Sort?
Bubble sort is a simple sorting algorithm that repeatedly compares adjacent elements and swaps them if they are in the wrong order.

It continues until the list becomes sorted.
